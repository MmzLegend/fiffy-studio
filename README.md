# Fiffy Studio

Architectural interior/exterior design studio demo. Static website with an original interactive Three.js villa and living room, finish and lighting controls, concept gallery, and a downloadable project brief.

The studio portfolio titles are fictional concepts. No contact submission or external messaging is enabled. Briefs download locally. Source imagery is credited in the site; original image authors retain their rights. Three.js is bundled under the MIT license in assets/THREE-LICENSE.txt.

Run locally: `python3 -m http.server 8771` then open http://localhost:8771.
